# 第十三章：一些常用的模板使用方法

## 模板的实用技巧

在前面的章节中，我们已经学习了 Django 模板的基础知识。这一章，我将分享一些在实际项目开发中常用的模板技巧和最佳实践。

## 模板中使用上下文处理器

Django 提供了上下文处理器（Context Processor）机制，可以在每个模板中自动注入变量。这常用于需要在多个页面使用的全局变量。

### 自定义上下文处理器

创建上下文处理器文件：

```python
# article/context_processors.py

from .models import Category, Tag

def common_context(request):
    """全局上下文处理器"""
    categories = Category.objects.all()
    tags = Tag.objects.all()[:20]  # 只获取前20个标签
    
    return {
        'categories': categories,
        'tags': tags,
        'site_name': '我的技术博客',
    }
```

在 settings.py 中注册上下文处理器：

```python
TEMPLATES = [
    {
        'BACKEND': 'django.template.backends.django.DjangoTemplates',
        'DIRS': [BASE_DIR / 'templates'],
        'APP_DIRS': True,
        'OPTIONS': {
            'context_processors': [
                # ... 其他处理器
                'article.context_processors.common_context',  # 添加这行
            ],
        },
    },
]
```

现在，`categories`、`tags` 和 `site_name` 变量会在所有模板中自动可用，不需要在每个视图中手动传递。

## 列表和字典操作

### 在模板中获取列表元素

```html
{# 获取列表的第一个元素 #}
{{ list.0 }}

{# 获取列表的最后一个元素 #}
{{ list|slice:"-1:" }}
```

### 在模板中使用字典

```html
{# 获取字典的值 #}
{{ dict.key }}
{{ dict|get_item:'key' }}
```

需要创建一个自定义过滤器：

```python
@register.filter
def get_item(dictionary, key):
    return dictionary.get(key)
```

## 日期时间格式化

Django 提供了丰富的日期格式化选项：

```html
{# 2024-05-20 #}
{{ post.created_time|date:"Y-m-d" }}

{# 2024年5月20日 #}
{{ post.created_time|date:"Y年m月d日" }}

{# 2024/05/20 14:30:00 #}
{{ post.created_time|date:"Y/m/d H:i:s" }}

{# 2024-05-20 14:30 #}
{{ post.created_time|date:"Y-m-d H:i" }}

{# 五月 20, 2024 #}
{{ post.created_time|date:"F j, Y" }}

{# 相对时间：2 days ago #}
{% load humanize %}
{{ post.created_time|naturaltime }}
```

需要在 INSTALLED_APPS 中添加 `django.contrib.humanize`。

## 分页显示的多种样式

### 简单分页

```html
<!-- templates/article/pagination.html -->

{% if page_obj.has_other_pages %}
<nav class="pagination">
    <ul>
        {% if page_obj.has_previous %}
        <li><a href="?page={{ page_obj.previous_page_number }}">上一页</a></li>
        {% else %}
        <li class="disabled">上一页</li>
        {% endif %}
        
        {% for num in page_obj.paginator.page_range %}
            {% if page_obj.number == num %}
            <li class="active">{{ num }}</li>
            {% elif num > page_obj.number|add:'-3' and num < page_obj.number|add:'3' %}
            <li><a href="?page={{ num }}">{{ num }}</a></li>
            {% endif %}
        {% endfor %}
        
        {% if page_obj.has_next %}
        <li><a href="?page={{ page_obj.next_page_number }}">下一页</a></li>
        {% else %}
        <li class="disabled">下一页</li>
        {% endif %}
    </ul>
</nav>
{% endif %}
```

### 带页码范围的分页

```html
{% load i18n %}

{% if is_paginated %}
<nav aria-label="分页" class="pagination-nav">
    <ul class="pagination">
        {% if page_obj.has_previous %}
        <li class="page-item">
            <a class="page-link" href="?page=1">首页</a>
        </li>
        <li class="page-item">
            <a class="page-link" href="?page={{ page_obj.previous_page_number }}">上一页</a>
        </li>
        {% endif %}
        
        {% for num in page_obj.paginator.page_range %}
            {% if page_obj.number == num %}
                <li class="page-item active">
                    <span class="page-link">{{ num }}</span>
                </li>
            {% elif num >= page_obj.number|add:'-3' and num <= page_obj.number|add:'3' %}
                <li class="page-item">
                    <a class="page-link" href="?page={{ num }}">{{ num }}</a>
                </li>
            {% elif num == 1 or num == page_obj.paginator.num_pages %}
                <li class="page-item">
                    <a class="page-link" href="?page={{ num }}">{{ num }}</a>
                </li>
                {% if num == 1 and page_obj.number|add:'-4' > 1 %}
                    <li class="page-item disabled">
                        <span class="page-link">...</span>
                    </li>
                {% endif %}
            {% endif %}
        {% endfor %}
        
        {% if page_obj.has_next %}
        <li class="page-item">
            <a class="page-link" href="?page={{ page_obj.next_page_number }}">下一页</a>
        </li>
        <li class="page-item">
            <a class="page-link" href="?page={{ page_obj.paginator.num_pages }}">末页</a>
        </li>
        {% endif %}
    </ul>
</nav>
{% endif %}
```

## 文章标签展示

### 标签云样式

```html
<div class="tag-cloud">
    {% for tag in tags %}
    <a href="{% url 'article:tag' tag.slug %}" 
       class="tag-{{ tag.posts.count|clamp:1,10 }}">
        {{ tag.name }}
    </a>
    {% endfor %}
</div>
```

需要创建 `clamp` 过滤器：

```python
@register.filter
def clamp(value, args):
    """限制值在范围内"""
    min_val, max_val = args.split(',')
    value = int(value)
    min_val = int(min_val)
    max_val = int(max_val)
    return max(min_val, min(value, max_val))
```

### 文章内标签列表

```html
<div class="article-tags">
    <span class="tag-label">标签：</span>
    {% for tag in post.tags.all %}
    <a href="{% url 'article:tag' tag.slug %}" class="tag-link">
        {{ tag.name }}
    </a>
    {% empty %}
    <span class="no-tag">暂无标签</span>
    {% endfor %}
</div>
```

## 富文本内容的处理

### 安全渲染富文本

```html
<!-- article/detail.html -->

<article class="article-content">
    {{ post.content|safe }}
</article>
```

### 截断富文本摘要

对于富文本内容，简单的 truncatewords 或 truncatechars 可能不够用，因为 HTML 标签会干扰截断逻辑。可以使用以下方法：

安装 `django-typer` 或手动处理：

```python
@register.filter
def truncate_html_chars(value, arg):
    """截断 HTML 内容"""
    from django.utils.html import strip_tags
    from django.template.defaultfilters import truncator
    
    # 先移除标签
    text = strip_tags(value)
    # 再截断
    return truncator.truncate_words(text, int(arg))
```

## 面包屑导航

```html
<!-- 模板中使用 -->
<nav aria-label="breadcrumb">
    <ol class="breadcrumb">
        <li class="breadcrumb-item">
            <a href="{% url 'article:index' %}">首页</a>
        </li>
        
        {% if category %}
        <li class="breadcrumb-item">
            <a href="{% url 'article:category' category.slug %}">
                {{ category.name }}
            </a>
        </li>
        {% endif %}
        
        <li class="breadcrumb-item active">{{ post.title|truncatechars:20 }}</li>
    </ol>
</nav>
```

## 空状态处理

```html
{% if page_obj %}
    {% for post in page_obj %}
        {# 显示文章 #}
    {% endfor %}
{% else %}
    <div class="empty-state">
        <h3>暂无文章</h3>
        {% if request.resolver_match.url_name == 'search' %}
        <p>没有找到与"{{ q }}"相关的文章</p>
        {% else %}
        <p>敬请期待更多精彩内容</p>
        {% endif %}
    </div>
{% endif %}
```

## 代码高亮

Summernote 使用 `<pre><code>` 标签包裹代码。Django 模板中需要特殊处理：

```html
<article class="article-content">
    {% load markdownify %}
    {{ post.content|markdownify }}
</article>
```

或者直接处理 Summernote 生成的 HTML：

```html
<article class="article-content">
    {{ post.content|safe }}
</article>

<style>
    pre {
        background: #f4f4f4;
        padding: 15px;
        border-radius: 5px;
        overflow-x: auto;
    }
    code {
        font-family: 'Fira Code', monospace;
    }
</style>
```

## 搜索表单

### 基础搜索框

```html
<form action="{% url 'article:search' %}" method="get" class="search-form">
    <div class="input-group">
        <input type="text" 
               name="q" 
               class="form-control" 
               placeholder="搜索文章..."
               value="{{ q|default:'' }}">
        <button type="submit" class="btn btn-primary">搜索</button>
    </div>
</form>
```

### 带搜索建议的搜索框

需要 JavaScript 配合：

```html
<form action="{% url 'article:search' %}" method="get" class="search-form">
    <div class="autocomplete-wrapper">
        <input type="text" 
               name="q" 
               id="search-input"
               class="form-control" 
               placeholder="搜索文章..."
               value="{{ q|default:'' }}"
               autocomplete="off">
        <div id="suggestions" class="suggestions"></div>
    </div>
    <button type="submit" class="btn btn-primary">搜索</button>
</form>
```
