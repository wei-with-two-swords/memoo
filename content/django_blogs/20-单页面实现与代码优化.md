# 第二十章：独立页面与项目总结

## 写在最后

经过前面十九章的学习，我们的博客系统已经初具规模——首页、文章列表、文章详情、标签页、搜索页，构成了一个功能完善的博客网站。

但仔细想想，一个真正的博客站点，还缺些什么呢？

或许是一个"关于"页面，让访客了解博客的主人；或许是一个"联系我"页面，方便志同道合的朋友与你取得联系。

## 单页面：一个网站的灵魂角落

独立页面是网站的"灵魂角落"。它们静静地站在那里，讲述着主人自己的故事。

### 创建单页面模型

```python
# article/models.py

class Page(models.Model):
    """单页面模型"""
    title = models.CharField('标题', max_length=100)
    slug = models.SlugField('URL别名', unique=True)
    content = models.TextField('内容')
    created_time = models.DateTimeField('创建时间', default=timezone.now)
    updated_time = models.DateTimeField('更新时间', auto_now=True)

    class Meta:
        verbose_name = '页面'
        verbose_name_plural = verbose_name

    def __str__(self):
        return self.title
```

> **提示**：单页面的content字段使用普通TextField即可，因为Admin中已配置了Summernote富文本编辑器。

### 编写视图函数

```python
# article/views.py

def page_detail(request, slug):
    """单页面详情视图"""
    page = get_object_or_404(Page, slug=slug)
    return render(request, 'article/page.html', {'page': page})
```

## 代码优化

### 使用模板标签封装查询

如果多个页面需要显示"最近文章"、"热门文章"等内容，可以使用模板标签：

```python
# article/templatetags/article_tags.py

from django import template
from ..models import Post, Category, Tag

register = template.Library()

@register.inclusion_tag('article/_recent_posts.html')
def get_recent_posts(num=5):
    return {'recent_posts': Post.objects.all()[:num]}

@register.inclusion_tag('article/_categories.html')
def get_categories():
    return {'categories': Category.objects.all()}

@register.inclusion_tag('article/_tags.html')
def get_tags():
    return {'tags': Tag.objects.all()[:20]}
```

在模板中使用：

```html
{% load article_tags %}
{% get_recent_posts 5 %}
{% get_categories %}
{% get_tags %}
```

### URL命名规范

一个好的URL设计：

```python
# 推荐
path('article/', views.article_list, name='article_list')
path('article/<slug:slug>/', views.article_detail, name='article_detail')

# 不推荐
path('article-list/', views.article_list, name='list')
path('article-detail/<int:id>/', views.article_detail, name='detail')
```

## 项目总结

### 功能清单

| 功能 | 路由 | 说明 |
|------|------|------|
| 首页 | `/` | 展示文章列表 |
| 文章详情 | `/article/<slug>/` | 展示文章内容 |
| 分类页 | `/category/<slug>/` | 按分类筛选 |
| 标签页 | `/tag/<slug>/` | 按标签筛选 |
| 搜索页 | `/search/` | 全文搜索 |
| 单页面 | `/page/<slug>/` | 关于、联系等 |
| Admin后台 | `/admin/` | 数据管理 |

### 最佳实践

1. **MTV模式**：Model负责数据，Template负责展示，View负责逻辑
2. **DRY原则**：使用模板继承、上下文处理器避免重复
3. **ORM优先**：尽量使用Django ORM，保持代码可移植
4. **安全意识**：CSRF保护、XSS防护
