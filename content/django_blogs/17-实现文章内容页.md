# 第十七章：实现文章内容页

## 文章详情页的重要性

如果说首页是博客的门面，文章详情页就是博客的灵魂。访客点击某篇文章的标题，最终到达的就是这个页面。好的详情页设计，要为读者创造一个安静、舒适的阅读空间。

## 文章详情页模板

```html
<!-- templates/article/detail.html -->

{% extends 'article/base.html' %}

{% block title %}{{ post.title }} - {{ site_name }}{% endblock %}

{% block content %}
<!-- 面包屑导航 -->
<nav aria-label="breadcrumb" class="mb-4">
    <ol class="breadcrumb">
        <li class="breadcrumb-item"><a href="{% url 'article:index' %}">首页</a></li>
        <li class="breadcrumb-item"><a href="{% url 'article:category' post.category.slug %}">{{ post.category.name }}</a></li>
        <li class="breadcrumb-item active">{{ post.title|truncatechars:15 }}</li>
    </ol>
</nav>

<article class="card">
    <div class="card-body">
        <h1 class="card-title mb-3">{{ post.title }}</h1>
        
        <p class="text-muted small mb-4">
            <span>{{ post.created_time|date:"Y年m月d日" }}</span>
            <span class="mx-2">|</span>
            <span>{{ post.views }} 阅读</span>
            <span class="mx-2">|</span>
            <a href="{% url 'article:category' post.category.slug %}">{{ post.category.name }}</a>
        </p>
        
        <div class="article-content mb-4">
            {{ post.content|safe }}
        </div>
        
        {% if post.tags.exists %}
        <div class="border-top pt-3">
            <span class="text-muted me-2">标签：</span>
            {% for tag in post.tags.all %}
            <a href="{% url 'article:tag' tag.slug %}" class="badge bg-secondary me-1">{{ tag.name }}</a>
            {% endfor %}
        </div>
        {% endif %}
    </div>
</article>

<!-- 上一篇下一篇 -->
<div class="d-flex justify-content-between mt-4">
    {% if post.get_previous_by_created_time %}
    <a href="{% url 'article:detail' post.get_previous_by_created_time.slug %}" class="btn btn-outline-secondary">
        ← {{ post.get_previous_by_created_time.title|truncatechars:20 }}
    </a>
    {% else %}
    <span></span>
    {% endif %}
    
    {% if post.get_next_by_created_time %}
    <a href="{% url 'article:detail' post.get_next_by_created_time.slug %}" class="btn btn-outline-secondary">
        {{ post.get_next_by_created_time.title|truncatechars:20 }} →
    </a>
    {% endif %}
</div>
{% endblock %}
```

## 视图函数

```python
# article/views.py

def article_detail(request, slug):
    """文章详情页"""
    post = get_object_or_404(Post, slug=slug)
    
    # 增加浏览量
    post.views += 1
    post.save(update_fields=['views'])
    
    return render(request, 'article/detail.html', {'post': post})
```

## 本章小结

本章实现了文章详情页：

1. **面包屑导航**：让用户知道当前位置
2. **文章元信息**：标题、时间、浏览量、分类
3. **`|safe`过滤器**：渲染富文本HTML内容
4. **标签展示**：方便用户按标签浏览相关文章
5. **上下篇导航**：方便连续阅读
6. **浏览量统计**：使用`update_fields`优化更新性能
