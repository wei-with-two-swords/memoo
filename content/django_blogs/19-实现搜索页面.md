# 第十九章：实现搜索页面

## 搜索功能的重要性

当博客文章数量增长到一定规模后，用户很难通过浏览来发现内容。搜索功能让用户能够根据关键词快速定位到感兴趣的文章。

## Q对象：构建复杂查询

Django的Q对象支持使用`&`（AND）、`|`（OR）、`~`（NOT）运算符组合查询条件：

```python
from django.db.models import Q

# OR查询：标题或内容包含关键词
Post.objects.filter(Q(title__icontains=q) | Q(content__icontains=q))

# 组合查询
Post.objects.filter(
    (Q(title__icontains='Django') | Q(title__icontains='Python')) &
    Q(views__gt=50)
)
```

## 搜索视图

```python
# article/views.py

def search(request):
    """搜索页面"""
    q = request.GET.get('q', '').strip()
    
    if q:
        # 搜索标题和正文
        post_list = Post.objects.filter(
            Q(title__icontains=q) | Q(content__icontains=q)
        ).distinct().order_by('-created_time')
    else:
        post_list = Post.objects.none()
    
    paginator = Paginator(post_list, 10)
    page_number = request.GET.get('page')
    page_obj = paginator.get_page(page_number)
    
    return render(request, 'article/search.html', {
        'q': q,
        'page_obj': page_obj,
    })
```

```html

{% extends 'article/base.html' %}

{% block title %}搜索 - {{ site_name }}{% endblock %}

{% block content %}
<!-- 搜索表单 -->
<div class="card mb-4">
    <div class="card-body">
        <form action="{% url 'article:search' %}" method="get" class="row g-3">
            <div class="col-md-10">
                <input type="search" name="q" class="form-control" 
                       placeholder="输入关键词搜索..." value="{{ q|default:'' }}">
            </div>
            <div class="col-md-2">
                <button type="submit" class="btn btn-primary w-100">搜索</button>
            </div>
        </form>
    </div>
</div>

{% if q %}
<!-- 搜索结果 -->
<div class="mb-3">
    {% if page_obj %}
    找到 {{ page_obj.paginator.count }} 篇与 "<strong>{{ q }}</strong>" 相关的文章
    {% else %}
    未找到与 "<strong>{{ q }}</strong>" 相关的文章
    {% endif %}
</div>

{% for post in page_obj %}
<article class="card mb-3">
    <div class="card-body">
        <h2 class="h5">
            <a href="{% url 'article:detail' post.slug %}">{{ post.title }}</a>
        </h2>
        <p class="text-muted small mb-2">
            {{ post.created_time|date:"Y年m月d日" }} | 
            <a href="{% url 'article:category' post.category.slug %}">{{ post.category.name }}</a>
        </p>
        <p class="mb-0">{{ post.excerpt|default:post.content|truncatechars:150 }}</p>
    </div>
</article>
{% empty %}
<div class="alert alert-info">
    <p class="mb-2">没有找到相关结果</p>
    <p class="mb-0 small">试试以下分类：</p>
    {% for category in categories|slice:":6" %}
    <a href="{% url 'article:category' category.slug %}" class="badge bg-secondary me-1">{{ category.name }}</a>
    {% endfor %}
</div>
{% endfor %}

<!-- 分页 -->
{% if page_obj.has_other_pages %}
<nav>
    <ul class="pagination justify-content-center">
        {% if page_obj.has_previous %}
        <li class="page-item"><a class="page-link" href="?q={{ q }}&page={{ page_obj.previous_page_number }}">上一页</a></li>
        {% endif %}
        <li class="page-item disabled"><span class="page-link">第 {{ page_obj.number }} / {{ page_obj.paginator.num_pages }} 页</span></li>
        {% if page_obj.has_next %}
        <li class="page-item"><a class="page-link" href="?q={{ q }}&page={{ page_obj.next_page_number }}">下一页</a></li>
        {% endif %}
    </ul>
</nav>
{% endif %}

{% else %}
<!-- 未搜索状态 -->
<div class="text-center py-5 text-muted">
    <p>输入关键词搜索感兴趣的文章</p>
    <p class="small">热门分类：</p>
    <div class="mt-3">
        {% for category in categories|slice:":6" %}
        <a href="{% url 'article:category' category.slug %}" class="badge bg-secondary me-1">{{ category.name }}</a>
        {% endfor %}
    </div>
</div>
{% endif %}
{% endblock %}
```
