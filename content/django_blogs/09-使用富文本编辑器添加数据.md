# 第九章：使用富文本编辑器添加数据

## 为什么需要富文本编辑器

在上一章中，我们已经在 Admin 后台创建了一些测试文章。但是，你可能已经注意到了，当我们在编辑文章的正文内容时，表单只是一个简单的文本框，无法设置文字格式、插入图片、添加代码块等。

对于一个技术博客来说，这种简单的文本框远远不够。我们需要能够：

- 设置标题、段落格式
- 插入图片
- 添加代码块（并高亮语法）
- 引用文字
- 创建列表
- 添加链接

这些功能对于技术文章来说几乎是必需的。富文本编辑器（Rich Text Editor）正是来解决这个问题的。

## 常见的 Django 富文本编辑器

Django 生态中有多个优秀的富文本编辑器插件，以下是几个比较流行的选择：

**Django CKEditor**：基于 CKEditor，功能非常强大，插件丰富，但配置相对复杂。

**Django Summernote**：基于 Bootstrap 和 Summernote，界面美观，与 Django 集成简单，文档友好。

**Django TinyMCE**：基于 TinyMCE，轻量级，易于使用。

**Django RichTextField**：一个更轻量级的选择，适合简单场景。

对于我们的博客项目，我选择 **Django Summernote** 作为富文本编辑器。它有以下优点：

1. 界面美观，与 Bootstrap 风格一致
2. 安装和配置简单
3. 功能足够强大，满足技术博客的需求
4. 支持图片上传
5. 中文文档友好

## 安装 Django Summernote

首先，确保你的虚拟环境已经激活，然后安装这个包：

```bash
pip install django-summernote
```

安装完成后，我们需要进行一些配置。

## 配置 Django Summernote

打开 `settings.py`，添加以下配置：

```python
# settings.py

INSTALLED_APPS = [
    # ...
    'django_summernote',
    'article',
]

# Summernote 配置
SUMMERNOTE_CONFIG = {
    'toolbar': [
        ['style', ['style']],
        ['font', ['bold', 'italic', 'underline', 'clear']],
        ['fontname', ['fontname']],
        ['para', ['ul', 'ol', 'paragraph']],
        ['height', ['height']],
        ['table', ['table']],
        ['insert', ['link', 'picture', 'video']],
        ['view', ['fullscreen', 'codeview']],
        ['help', ['help']],
    ],
    'placeholder': '在这里输入文章内容...',
    'width': '100%',
    'height': '500',
    'airMode': False,
}
```

这是一个比较完整的工具栏配置。你可以根据需要简化或调整它。

## 更新模型字段

现在，我们需要修改 Post 模型，将 `content` 字段从普通的 `TextField` 改为 Summernote 的字段类型。

打开 `article/models.py`：

```python
# article/models.py

from django.db import models
from django.utils import timezone
from django_summernote.models import Attachment
from django_summernote.fields import SummernoteTextField


class Post(models.Model):
    # ... 其他字段 ...
    
    # 使用 Summernote 的富文本字段
    content = SummernoteTextField('正文')
    
    # ... 其他内容 ...
```

不过，更好的做法是保持模型的通用性，将字段类型留在表单层面处理。这样，即使将来换用其他富文本编辑器，也不需要修改模型。

我们可以创建一个自定义字段类，或者在 Admin 中直接指定表单 widgets。

## 在 Admin 中配置富文本编辑器

最简单的方式是在 Admin 中直接配置富文本编辑器，而不需要修改模型。

```python
# article/admin.py

from django.contrib import admin
from django_summernote.admin import SummernoteModelAdmin
from .models import Post, Category, Tag


class PostAdmin(SummernoteModelAdmin):
    """文章管理界面 - 使用富文本编辑器"""
    list_display = ['title', 'category', 'created_time', 'views']
    list_filter = ['category', 'tags', 'created_time']
    search_fields = ['title', 'content']
    date_hierarchy = 'created_time'
    ordering = ['-created_time']
    prepopulated_fields = {'slug': ('title',)}
    
    # 使用 Summernote 的表单字段
    summernote_fields = ('content', 'excerpt')
    
    fieldsets = (
        ('基本信息', {
            'fields': ('title', 'slug', 'category')
        }),
        ('内容', {
            'fields': ('content', 'excerpt')
        }),
        ('标签', {
            'fields': ('tags',)
        }),
        ('统计', {
            'fields': ('views',),
            'classes': ('collapse',)
        }),
    )


@admin.register(Category)
class CategoryAdmin(admin.ModelAdmin):
    list_display = ['name', 'slug', 'post_count', 'created_time']
    search_fields = ['name']
    prepopulated_fields = {'slug': ('name',)}
    
    def post_count(self, obj):
        return obj.posts.count()
    
    post_count.short_description = '文章数量'


@admin.register(Tag)
class TagAdmin(admin.ModelAdmin):
    list_display = ['name', 'slug', 'post_count', 'created_time']
    search_fields = ['name']
    prepopulated_fields = {'slug': ('name',)}
    
    def post_count(self, obj):
        return obj.posts.count()
    
    post_count.short_description = '文章数量'


admin.site.register(Post, PostAdmin)
```

关键的变化是让 `PostAdmin` 继承自 `SummernoteModelAdmin`，然后在 `summernote_fields` 中指定哪些字段使用富文本编辑器。

## 配置 URL

Summernote 需要一些额外的 URL 来处理图片上传和预览等功能。打开 `blog/urls.py`，添加 Summernote 的 URL：

```python
# blog/urls.py

from django.contrib import admin
from django.urls import path, include
from django.conf import settings
from django.conf.urls.static import static

urlpatterns = [
    path('admin/', admin.site.urls),
    path('summernote/', include('django_summernote.urls')),  # 添加这行
    path('', include('article.urls', namespace='article')),
]

# 添加媒体文件的 URL（仅开发环境使用）
if settings.DEBUG:
    urlpatterns += static(settings.MEDIA_URL, document_root=settings.MEDIA_ROOT)
```

## Summernote 进阶配置

Summernote 提供了很多配置选项，让我们来了解更多高级用法。

### 配置代码块高亮

Summernote 自带的代码块功能比较简单。如果你需要更好的代码高亮效果，可以集成 Prism.js 或 highlight.js。

首先，下载 Prism.js 的 CSS 和 JS 文件，放在 static 目录下：

```
static/
├── css/
│   └── prism.css
└── js/
    └── prism.js
```

然后，创建一个自定义的 Summernote 配置：

```python
# article/admin.py

from django.contrib import admin
from django_summernote.admin import SummernoteModelAdmin
from django_summernote.widgets import SummernoteWidget
from .models import Post, Category, Tag


class PostAdmin(SummernoteModelAdmin):
    list_display = ['title', 'category', 'created_time', 'views']
    list_filter = ['category', 'tags', 'created_time']
    search_fields = ['title', 'content']
    date_hierarchy = 'created_time'
    ordering = ['-created_time']
    prepopulated_fields = {'slug': ('title',)}
    summernote_fields = ('content', 'excerpt')
    
    # 自定义 JS 和 CSS
    class Media:
        css = {
            'all': ('css/prism.css',)
        }
        js = ('js/prism.js',)
```

如果想禁用某个功能，可以将该按钮从工具栏中移除：

```python

SUMMERNOTE_CONFIG = {
    'toolbar': [
        ['insert', ['link', 'picture']],  # 移除了 video
    ],

```

### 设置编辑器的默认值

如果想在编辑器中预设一些默认内容，可以在 formfield 中指定：

```python
class PostAdmin(SummernoteModelAdmin):
    def get_form(self, request, obj=None, **kwargs):
        form = super().get_form(request, obj, **kwargs)
        if not obj:  # 新建对象时
            form.base_fields['content'].initial = '<p>文章内容...</p>'
        return form
```

## 处理图片上传

Summernote 默认将图片上传到 Django 的媒体目录，并记录在 Attachment 表中。

你可以在 Admin 后台的 "Attachments" 页面查看和管理所有上传的文件。

如果需要自定义图片上传的行为，可以在 settings.py 中配置：

```python
# 设置 Summernote 上传文件的大小限制（单位：字节）
SUMMERNOTE_CONFIG = {
    'attachment_upload_to': lambda instance, filename: f'attachments/{filename}',
    'attachment_filesize_limit': 10 * 1024 * 1024,  # 10MB
}
```

## 富文本内容的安全问题

从用户提交的内容中渲染 HTML 存在 XSS（跨站脚本攻击）风险。Summernote 默认会过滤一些危险的 HTML 标签和属性。

Django 的模板引擎在渲染内容时，默认也会转义 HTML 特殊字符。所以，当你在模板中输出富文本内容时，需要注意：

```html
<!-- 安全的方式：使用 safe 过滤器标记内容为安全 -->
{{ post.content|safe }}

<!-- 或者使用 autoescape 标签 -->
{% autoescape off %}
    {{ post.content }}
{% endautoescape %}
```

`safe` 过滤器告诉 Django 这个内容是安全的，不需要转义。如果内容来自不可信的用户，最好使用 ` bleach` 等库来清理 HTML，只保留安全的标签和属性。
