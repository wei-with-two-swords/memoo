# 第十五章：实现网站首页

## 首页的重要性

如果把一个博客比作一家书店，那么首页就是书店的门脸。精心设计的门面，能够在瞬间传达网站的主题、风格，让访客产生阅读的冲动。

这一章，我们将一起创建博客的首页。

## 创建基础模板

使用Bootstrap框架，我们只需写少量自定义CSS：

```html
<!-- templates/article/base.html -->

{% load static %}

<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <meta name="description" content="分享技术心得，记录生活感悟">
    <title>{% block title %}{{ site_name }}{% endblock %}</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css" rel="stylesheet">
    <style>
        body { background-color: #f5f5f5; }
        .navbar-brand { font-weight: bold; }
        footer { background: #2c3e50; color: #fff; }
        .article-card { transition: transform 0.2s; }
        .article-card:hover { transform: translateY(-3px); }
        .article-meta { color: #888; font-size: 0.875rem; }
        .tag-item { display: inline-block; padding: 0.2rem 0.5rem; background: #e9ecef; border-radius: 4px; font-size: 0.8rem; text-decoration: none; color: #495057; }
        .tag-item:hover { background: #0d6efd; color: #fff; }
    </style>
</head>
<body>
    <!-- 导航栏 -->
    <nav class="navbar navbar-expand-lg navbar-dark mb-4" style="background-color: #2c3e50;">
        <div class="container">
            <a class="navbar-brand" href="{% url 'article:index' %}">{{ site_name }}</a>
            <button class="navbar-toggler" type="button" data-bs-toggle="collapse" data-bs-target="#navbarNav">
                <span class="navbar-toggler-icon"></span>
            </button>
            <div class="collapse navbar-collapse" id="navbarNav">
                <ul class="navbar-nav ms-auto">
                    <li class="nav-item"><a class="nav-link" href="{% url 'article:index' %}">首页</a></li>
                    <li class="nav-item"><a class="nav-link" href="{% url 'article:search' %}">搜索</a></li>
                </ul>
            </div>
        </div>
    </nav>

    <!-- 主内容 -->
    <main class="container">
        <div class="row">
            <div class="col-lg-8">
                {% block content %}{% endblock %}
            </div>
            <div class="col-lg-4">
                {% include 'article/sidebar.html' %}
            </div>
        </div>
    </main>

    <!-- 页脚 -->
    <footer class="mt-5 py-4">
        <div class="container text-center">
            <p class="mb-1">{{ site_name }}</p>
            <p class="small mb-0">Powered by Django</p>
        </div>
    </footer>

    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## 创建首页模板

```html
<!-- templates/article/index.html -->

{% extends 'article/base.html' %}

{% block title %}首页 - {{ site_name }}{% endblock %}

{% block content %}
{% for post in page_obj %}
<article class="card mb-4">
    <div class="card-body">
        <h2 class="card-title">
            <a href="{% url 'article:detail' post.slug %}" class="text-decoration-none">{{ post.title }}</a>
        </h2>
        <p class="text-muted small mb-2">
            <span>{{ post.created_time|date:"Y年m月d日" }}</span>
            <span class="mx-2">|</span>
            <a href="{% url 'article:category' post.category.slug %}">{{ post.category.name }}</a>
        </p>
        <p class="card-text">{{ post.excerpt|default:post.content|truncatechars:200 }}</p>
        <a href="{% url 'article:detail' post.slug %}" class="btn btn-outline-primary btn-sm">阅读全文</a>
    </div>
</article>
{% empty %}
<div class="alert alert-info">暂无文章</div>
{% endfor %}

<!-- 分页 -->
{% if page_obj.has_other_pages %}
<nav>
    <ul class="pagination justify-content-center">
        {% if page_obj.has_previous %}
        <li class="page-item"><a class="page-link" href="?page=1">首页</a></li>
        <li class="page-item"><a class="page-link" href="?page={{ page_obj.previous_page_number }}">上一页</a></li>
        {% endif %}
        <li class="page-item disabled"><span class="page-link">第 {{ page_obj.number }} / {{ page_obj.paginator.num_pages }} 页</span></li>
        {% if page_obj.has_next %}
        <li class="page-item"><a class="page-link" href="?page={{ page_obj.next_page_number }}">下一页</a></li>
        <li class="page-item"><a class="page-link" href="?page={{ page_obj.paginator.num_pages }}">末页</a></li>
        {% endif %}
    </ul>
</nav>
{% endif %}
{% endblock %}
```

## 配置全局上下文

为了让所有模板都能访问`site_name`、`categories`、`tags`，创建一个上下文处理器：

```python
# article/context_processors.py

from .models import Category, Tag

def common_context(request):
    return {
        'site_name': '我的技术博客',
        'categories': Category.objects.all(),
        'tags': Tag.objects.all()[:20],
    }
```

然后在settings.py中注册：

```python
TEMPLATES = [
    {
        'OPTIONS': {
            'context_processors': [
                # ... 其他处理器
                'article.context_processors.common_context',
            ],
        },
    },
]
```

## 本章小结

这一章我们创建了：
- 基础模板`base.html`：使用Bootstrap，快速搭建响应式布局
- 侧边栏组件`sidebar.html`：复用导航元素
- 首页模板`index.html`：展示文章列表
- 全局上下文处理器：统一提供站点配置

Bootstrap帮我们处理了大部分样式工作，我们只需写少量CSS来微调细节。
