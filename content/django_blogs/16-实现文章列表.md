# 第十六章：实现分类页面

## 分类页面的意义

博客系统需要让用户能够按分类浏览文章。分类是博客内容组织的第一层结构，比标签更加稳定和层次化。

## 分类页面模板

```html
<!-- templates/article/category.html -->

{% extends 'article/base.html' %}

{% block title %}{{ category.name }} - 分类 - {{ site_name }}{% endblock %}

{% block content %}
<!-- 页面标题 -->
<div class="card mb-4">
    <div class="card-body">
        <h1 class="mb-2">分类：{{ category.name }}</h1>
        <p class="text-muted mb-0">共 {{ page_obj.paginator.count }} 篇文章</p>
    </div>
</div>

<!-- 面包屑导航 -->
<nav aria-label="breadcrumb" class="mb-4">
    <ol class="breadcrumb">
        <li class="breadcrumb-item"><a href="{% url 'article:index' %}">首页</a></li>
        <li class="breadcrumb-item active">{{ category.name }}</li>
    </ol>
</nav>

<!-- 文章列表 -->
{% for post in page_obj %}
<article class="card mb-3">
    <div class="card-body">
        <h2 class="h5">
            <a href="{% url 'article:detail' post.slug %}">{{ post.title }}</a>
        </h2>
        <p class="text-muted small mb-2">
            {{ post.created_time|date:"Y年m月d日" }} | 
            <a href="{% url 'article:category' post.category.slug %}">{{ post.category.name }}</a> |
            {{ post.views }} 阅读
        </p>
        <p class="mb-2">{{ post.excerpt|default:post.content|truncatechars:150 }}</p>
        {% if post.tags.exists %}
        <div class="mt-2">
            {% for tag in post.tags.all %}
            <a href="{% url 'article:tag' tag.slug %}" class="badge bg-secondary me-1">{{ tag.name }}</a>
            {% endfor %}
        </div>
        {% endif %}
    </div>
</article>
{% empty %}
<div class="alert alert-info">该分类下暂无文章</div>
{% endfor %}

<!-- 分页 -->
{% if page_obj.has_other_pages %}
<nav>
    <ul class="pagination justify-content-center">
        {% if page_obj.has_previous %}
        <li class="page-item"><a class="page-link" href="?page={{ page_obj.previous_page_number }}">上一页</a></li>
        {% endif %}
        <li class="page-item disabled"><span class="page-link">第 {{ page_obj.number }} / {{ page_obj.paginator.num_pages }} 页</span></li>
        {% if page_obj.has_next %}
        <li class="page-item"><a class="page-link" href="?page={{ page_obj.next_page_number }}">下一页</a></li>
        {% endif %}
    </ul>
</nav>
{% endif %}
{% endblock %}
```

## 视图函数

```python
# article/views.py

def category_page(request, slug):
    """分类页面"""
    category = get_object_or_404(Category, slug=slug)
    post_list = category.posts.all()
    
    paginator = Paginator(post_list, 10)
    page_number = request.GET.get('page')
    page_obj = paginator.get_page(page_number)
    
    return render(request, 'article/category.html', {
        'category': category,
        'page_obj': page_obj,
    })
```
