# 第十二章：体验数据查询

## Django ORM 的魅力

Django 的 ORM（对象关系映射）系统是它最受欢迎的特性之一。它让我们可以用 Python 代码来操作数据库，而不需要编写 SQL 语句。

在这一章中，我将带你深入探索 Django ORM 的查询功能，掌握各种数据查询的技巧和方法。

## 模型管理器

每个 Django 模型都有一个默认的 `objects` 管理器，用于执行数据库查询。

```python
from article.models import Post

# 获取所有文章
all_posts = Post.objects.all()

# 获取单篇文章
post = Post.objects.get(id=1)
```

## 基本查询

### 获取所有对象

```python
# 获取所有文章
all_posts = Post.objects.all()
```

`all()` 返回一个 QuerySet，包含所有记录。

### 获取单个对象

```python
# 根据主键获取
post = Post.objects.get(pk=1)

# 根据其他字段获取
post = Post.objects.get(slug='django-getting-started')
```

注意：`get()` 只返回一条记录。如果有多条匹配或没有匹配，会抛出异常：
- 没有找到：`Post.DoesNotExist`
- 多于一条：`Post.MultipleObjectsReturned`

为了安全起见，可以使用 `get_object_or_404()`：

```python
from django.shortcuts import get_object_or_404

post = get_object_or_404(Post, slug='django-getting-started')
```

### 过滤查询

`filter()` 返回满足条件的 QuerySet：

```python
# 获取分类为 'django' 的所有文章
django_posts = Post.objects.filter(category__slug='django')

# 获取浏览量大于 100 的文章
popular_posts = Post.objects.filter(views__gte=100)

# 获取标题包含 'Django' 的文章
django_titles = Post.objects.filter(title__icontains='django')
```

### 排除查询

`exclude()` 返回不满足条件的 QuerySet：

```python
# 获取浏览量不大于 100 的文章
not_popular = Post.objects.exclude(views__gt=100)
```

### 链式调用

QuerySet 支持链式调用，可以组合多个过滤条件：

```python
# 获取分类为 'django' 且浏览量大于 100 的文章
posts = Post.objects.filter(category__slug='django').filter(views__gt=100)

# 或者
posts = Post.objects.filter(category__slug='django', views__gt=100)
```

## 查询条件

Django 提供了丰富的查询条件（查找），用于构建复杂的查询。

### 精确匹配

```python
Post.objects.get(title='Django入门')  # 精确匹配
Post.objects.get(title__exact='Django入门')  # 同上
Post.objects.get(title__iexact='django入门')  # 不区分大小写
```

### 包含

```python
Post.objects.filter(title__contains='Django')  # 区分大小写
Post.objects.filter(title__icontains='django')  # 不区分大小写
```

### 开头和结尾

```python
Post.objects.filter(title__startswith='Django')  # 开头匹配
Post.objects.filter(title__endswith='入门')  # 结尾匹配
```

### 大小比较

```python
Post.objects.filter(views__gt=100)  # 大于
Post.objects.filter(views__gte=100)  # 大于等于
Post.objects.filter(views__lt=100)  # 小于
Post.objects.filter(views__lte=100)  # 小于等于
```

### 范围

```python
from datetime import datetime

Post.objects.filter(created_time__year=2024)  # 年份
Post.objects.filter(created_time__month=5)  # 月份
Post.objects.filter(created_time__day=20)  # 日期
Post.objects.filter(created_time__range=[start_date, end_date])  # 日期范围
```

### 是否为空

```python
Post.objects.filter(excerpt__isnull=True)  # 摘要为空
Post.objects.filter(excerpt__exact='')  # 摘要为空字符串
Post.objects.filter(excerpt__in=['', None])  # 摘要为空或None
```

### 列表中的任意一个

```python
Post.objects.filter(category__slug__in=['django', 'python'])
# 获取分类 slug 为 'django' 或 'python' 的文章
```

## 关系查询

Django ORM 最强大的特性之一是能够跨关系查询。

### 外键查询

```python
# 获取文章的所有分类
post = Post.objects.get(id=1)
category = post.category

# 反向查询：获取某分类下的所有文章
from article.models import Category

category = Category.objects.get(slug='django')
posts = category.posts.all()  # 使用 related_name
```

### 跨关系查询

使用双下划线 `__` 可以跨关系查询：

```python
# 获取分类名称为 'Django' 的所有文章
posts = Post.objects.filter(category__name='Django')

# 获取标签 slug 为 'django-tutorial' 的所有文章
posts = Post.objects.filter(tags__slug='django-tutorial')

# 获取分类名称包含 'Python' 的所有文章
posts = Post.objects.filter(category__name__icontains='python')
```

### 多对多关系查询

```python
# 获取包含特定标签的所有文章
posts = Post.objects.filter(tags__slug='tutorial')

# 获取同时包含多个标签的文章
posts = Post.objects.filter(tags__slug__in=['django', 'tutorial']).distinct()

# 获取标签为 'django-tutorial' 的标签对象
tag = Tag.objects.get(slug='django-tutorial')
# 然后获取所有使用该标签的文章
posts = tag.posts.all()
```

## 排序

### order_by

```python
# 按创建时间升序
Post.objects.order_by('created_time')

# 按创建时间降序
Post.objects.order_by('-created_time')

# 多字段排序
Post.objects.order_by('-created_time', 'title')
```

### 默认排序

可以在模型的 Meta 类中设置默认排序：

```python
class Meta:
    ordering = ['-created_time']  # 默认按创建时间降序
```

## 切片和分页

QuerySet 支持 Python 列表的切片语法：

```python
# 获取前 5 篇文章
posts = Post.objects.all()[:5]

# 获取第 6-10 篇文章
posts = Post.objects.all()[5:10]
```

注意：切片不支持负数索引。

### 分页

```python
from django.core.paginator import Paginator

paginator = Paginator(Post.objects.all(), 10)  # 每页 10 篇
page = paginator.get_page(page_number)  # 获取第 page_number 页
```

或者在视图中更简洁地处理：

```python
def index(request):
    post_list = Post.objects.all()
    paginator = Paginator(post_list, 10)
    page_number = request.GET.get('page')
    page_obj = paginator.get_page(page_number)
    
    context = {'page_obj': page_obj}
    return render(request, 'article/index.html', context)
```

## 聚合和统计

Django 提供了聚合功能，可以对数据进行统计分析。

### 基本聚合

```python
from django.db.models import Count, Avg, Max, Min, Sum

# 统计文章总数
Post.objects.count()

# 统计每个分类的文章数量
from django.db.models import Count
Category.objects.annotate(post_count=Count('posts'))
```

### annotate 和 aggregate

`annotate()` 为每个对象添加注解：

```python
from django.db.models import Count

# 获取每个分类及其文章数量
categories = Category.objects.annotate(post_count=Count('posts'))

for category in categories:
    print(f'{category.name}: {category.post_count} 篇')
```

`aggregate()` 返回汇总结果：

```python
from django.db.models import Avg

# 计算所有文章的平均浏览量
avg_views = Post.objects.aggregate(Avg('views'))
print(avg_views)  # {'views__avg': 123.45}
```

### 分组统计

```python
# 统计每个分类的文章数量，并按数量降序排序
from django.db.models import Count

categories = Category.objects.annotate(
    post_count=Count('posts')
).order_by('-post_count')
```

## Q 对象与复杂查询

`Q` 对象用于构建复杂的查询条件。

```python
from django.db.models import Q

# 获取标题包含 'Django' 或 'Python' 的文章
Post.objects.filter(Q(title__icontains='django') | Q(title__icontains='python'))

# 获取标题包含 'Django' 且浏览量大于 100 的文章
Post.objects.filter(Q(title__icontains='django') & Q(views__gt=100))

# 获取标题不包含 'Django' 的文章
Post.objects.filter(~Q(title__icontains='django'))
```

### Q 对象组合

```python
# 查询条件：标题包含 'Django' 或者（分类是 'python' 且浏览量大于 100）
Post.objects.filter(
    Q(title__icontains='django') |
    (Q(category__name='python') & Q(views__gt=100))
)
```

## 查询优化

### only 和 defer

```python
# 只获取标题和内容，不获取其他字段
Post.objects.only('title', 'content')

# 不获取正文内容，减少数据传输
Post.objects.defer('content')
```

### select_related

`select_related` 用于预加载外键关系，减少数据库查询次数：

```python
# 获取所有文章，并预加载分类信息
# 这样访问 post.category 时不会触发额外查询
posts = Post.objects.select_related('category').all()
```

```python
# 预加载多级关系
posts = Post.objects.select_related('category', 'author').all()
```

### prefetch_related

`prefetch_related` 用于预加载多对多关系：

```python
# 预加载标签信息
posts = Post.objects.prefetch_related('tags').all()

# 预加载嵌套关系
posts = Post.objects.prefetch_related('tags', 'category').all()
```

### 选择使用

- `select_related`：一对一或多对一关系（ForeignKey）
- `prefetch_related`：多对多或反向外键关系（ManyToManyField）

### distinct

去除重复结果：

```python
# 获取所有文章的分类（不重复）
categories = Category.objects.filter(posts__isnull=False).distinct()
```

## 值的获取

### values 和 values_list

```python
# 获取标题列表
Post.objects.values_list('title', flat=True)
# ['Django入门', 'Python基础', ...]

# 获取标题和创建时间的字典列表
Post.objects.values('title', 'created_time')
# [{'title': 'Django入门', 'created_time': datetime(...), ...}, ...]
```

### 字段切片

```python
# 获取所有标题（不获取其他字段）
Post.objects.values_list('title', flat=True)
```

## 创建、更新、删除

### 创建对象

```python
# 方式一：实例化后保存
category = Category(name='Python', slug='python')
category.save()

# 方式二：使用 create
category = Category.objects.create(name='Python', slug='python')

# 方式三：使用 get_or_create
category, created = Category.objects.get_or_create(
    name='Python',
    slug='python'
)
```

### 更新对象

```python
# 单个对象更新
post = Post.objects.get(id=1)
post.title = '新标题'
post.save()  # 保存所有字段

# 指定字段更新（更高效）
post.title = '新标题'
post.save(update_fields=['title'])  # 只更新 title 字段

# 批量更新
Post.objects.filter(category__slug='django').update(views=0)
```

### 删除对象

```python
# 删除单个对象
post = Post.objects.get(id=1)
post.delete()

# 批量删除
Post.objects.filter(views__lt=10).delete()
```

## 实战：常用查询示例

### 获取最新 N 篇文章

```python
recent_posts = Post.objects.all()[:10]
```

### 获取热门文章（浏览量最高）

```python
popular_posts = Post.objects.order_by('-views')[:10]
```

### 获取某分类的最新文章

```python
category = Category.objects.get(slug='django')
recent_in_category = category.posts.all()[:5]
```

### 获取某标签的所有文章

```python
tag = Tag.objects.get(slug='tutorial')
tagged_posts = tag.posts.all()
```

### 获取文章数最多的分类

```python
from django.db.models import Count

top_categories = Category.objects.annotate(
    post_count=Count('posts')
).order_by('-post_count')[:5]
```

### 搜索文章

```python
def search_posts(query):
    return Post.objects.filter(
        Q(title__icontains=query) |
        Q(content__icontains=query)
    )
```

## 本章小结

在这一章中，我们深入学习了 Django ORM 的查询功能：

1. **基本查询**：`all()`、`get()`、`filter()`、`exclude()`
2. **查询条件**：各种查找类型，如 `__gt`、`__contains`、`__icontains`、`__year` 等
3. **关系查询**：跨外键和多对多关系的查询
4. **排序**：使用 `order_by()` 和 Meta 中的 `ordering`
5. **分页**：使用 Paginator 类进行分页
6. **聚合统计**：使用 `annotate()` 和 `aggregate()` 进行统计分析
7. **Q 对象**：构建复杂的 OR、AND、NOT 查询
8. **查询优化**：`select_related()`、`prefetch_related()`、`only()`、`defer()`
9. **CRUD 操作**：创建、更新、删除对象

这些查询技巧将贯穿整个博客系统的开发过程。熟练掌握它们，能让你的代码更加简洁和高效。
